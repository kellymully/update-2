The **Edit button** in the page  allows you to change or update existing information. When you click it, a form opens with the current data already filled in, and you can modify things like a command description or lesson content, then save the changes to update the system.

It has a blue background color.

The **Delete button** is used to remove an item completely. When clicked, it usually asks for confirmation to prevent mistakes, and once confirmed, the selected command, lesson, or topic is permanently deleted from the system.
